# 简历项目描述模板（中文）

## 项目名称

数学小帮手（MathHelperCpp）| C++ 工程化重构项目

## 一句话简介

将课程设计原型重构为基于 VS + CMake 的现代 C++ 项目，完整实现分层架构、可复用构建与可执行回归测试。

## 项目时间（示例）

2026.03 - 2026.03

## 技术栈

C++20、CMake、Visual Studio 2022、STL、文件持久化（TSV）

## 职责与成果（可直接粘贴）

- 负责将 1000+ 行单文件 C 风格程序拆分为 `UI/应用/领域/数据` 四层架构，显著提升可维护性与可扩展性。
- 设计并落地 `Student / IStudentRepository / QuizService / SessionService` 等核心接口，完成业务规则与交互流程解耦。
- 搭建标准化 CMake 工程，配置 `CMakePresets` 支持 VS 2022 Debug/Release 一键构建运行。
- 保留并升级核心业务：登录、分年级口算训练、六年级应用题训练、排行榜分页与成绩持久化。
- 修复原实现关键质量问题（随机数重复播种、输入容错薄弱、拼写错误命令等），提升稳定性与可演示性。
- 编写零依赖 `smoke` 自测程序，覆盖题型分流、判题精度、排行榜排序、文件读写兼容等核心路径。

## 量化亮点（可选）

- 代码结构由单文件重构为多模块工程，核心逻辑可独立复用。
- 实现 5 大类回归测试场景，支持快速验收核心规则正确性。
- 保持历史数据格式兼容，老版本 `student.txt` 可直接迁移运行。

## 面试讲解提纲（30-60 秒）

- 背景：原项目功能完整但工程化薄弱，不适合团队协作和长期维护。
- 方案：围绕“分层+接口+构建+测试”四件事做系统重构。
- 结果：在不丢业务功能的前提下，项目从课程作业升级为可用于 C++ 岗位面试展示的工程化作品。
