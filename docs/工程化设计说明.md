# 工程化设计说明（面试版）

## 1. 重构目标

基于课程设计原型，完成以下升级：

- 单文件 C 风格实现 -> 现代 C++ 分层工程。
- 手工编译 -> VS 可直接打开的 CMake 项目。
- 仅人工验证 -> 增加可重复执行的自测程序。
- 代码与文档并重，形成可讲、可跑、可扩展的面试项目。

## 2. 架构决策

### 2.1 分层边界

- `UI 层`：只负责交互展示与输入采集（`ConsoleUi`）。
- `应用层`：只负责流程编排和状态管理（`SessionService`）。
- `领域层`：只负责出题、判题、排序规则（`QuizService` / `BuildLeaderboard`）。
- `数据层`：只负责数据读写（`IStudentRepository` / `FileStudentRepository`）。

### 2.2 关键接口

- `Student`：统一学生模型（姓名、年级、累计分数）。
- `IStudentRepository`：仓储抽象，支持未来扩展到 SQLite/HTTP。
- `QuizService`：口算题与应用题规则中心，单点维护判题逻辑。
- `SessionService`：登录、菜单、训练与排行榜流程编排。

## 3. 重点改进项

### 3.1 随机数与题目生成

- 改为 `std::mt19937` 在程序初始化时一次性种子注入，避免循环内 `srand(time(NULL))` 带来的随机质量问题。
- 保留原年级策略：
  - 一年级：一位数加减
  - 二/三年级：两位数加减乘除（除法构造成整除）
  - 四/五年级：一位小数四则运算
  - 六年级：在小数运算基础上加入乘方与取余
  - 七年级：在六年级基础上加入复数四则运算

### 3.2 输入容错

- 全面采用 `getline + 解析校验`，避免 `scanf` 在非法输入场景下的状态污染。
- 菜单输入、数值输入、复数输入均有显式错误提示与重试机制。

### 3.3 数据兼容

- 延续 `student.txt` 的制表分隔格式：`name\tgrade\tscore`。
- 首次运行自动创建数据文件，兼容历史样本直接迁移。

### 3.4 排行榜

- 排序逻辑集中到 `BuildLeaderboard`，使用稳定排序，主键为分数降序，次键为姓名升序，便于测试与维护。

## 4. 构建与验证

- 构建系统：`CMake + CMakePresets`。
- 目标程序：
  - `mathhelper_cli`：正式演示
  - `mathhelper_smoke`：零依赖回归
- 编译标准：`C++20`。
- 警告策略：MSVC `/W4 /permissive- /utf-8`。

## 5. 自测覆盖点

- 四则运算与复数判题精度。
- 六/七年级题型分流覆盖。
- 应用题周长面积判题正确性。
- 排行榜排序结果稳定性。
- `student.txt` 读写兼容性。
